## Cylinder3D 真值级语义落地（本会话完成）
- 决策：走 **mmdet3d 原生推理**（非 xinge008 原版 demo）——框架自带权重、零 key 映射风险；xinge008 的 load_checkpoint 是精确 key 匹配，mmdet 的 .pth 喂不进去。
- 权重源：openmmlab 直达 `cylinder3d_4xb4_3x_semantickitti_20230318_191107-822a8c31.pth`（219MB），存 `Cylinder3D/model_load_dir/cylinder3d_mmdet3d.pth`；Google Drive/HF 被墙，BaiduPCS 需登录，均不可用。
- 栈版本（cu121/torch2.4.1 唯一 mmcv 预编译是 2.2.0）：mmdet3d==1.4.0 + mmcv==2.2.0 + mmdet==3.3.0 + mmengine==0.10.7。mmdet/mmdet3d 的 __init__ 有 `mmcv<2.2.0` 上界断言，已 sed 改成 `<2.3.0`（mmcv 2.2.0 与 2.1.x 同 2.x API，安全）。
- spconv 2.3.6 源码编译成功（PATH 加 `/usr/local/cuda-12.1/bin`；依赖 cumm/nvcc 12.1）。
- **关键坑：intensity 必须 /255**。SemanticKITTI 训练用 0–1 量纲，我们原始 0–255 差百倍 → 56% 点被错判 traffic-sign；÷255 后分布正常（sidewalk/terrain/road/veg/building 主导）。
- 推理 API：`init_model(cyl_config, pth)` + `inference_segmentor(model, bin)`；返回 Det3DDataSample，标签在 `result[0].pred_pts_seg.pts_semantic_mask`，**长度==N（逐点对齐输入），无需 scatter**。配置 `venv/.../mmdet3d/.mim/configs/cylinder3d/cylinder3d_4xb4-3x_semantickitti.py`；圆柱体素 `point_cloud_range=[0,-π,-4,50,π,2]`，超出范围点极少（本场景 clip_frac≈0.3%），模型 clamp 进边界体素照常出标签。
- cyl_infer.py（远端 /root/gpufree-data/slam_comp/cyl_infer.py）：扫描读 run/scans/*.pcd(x,y,z,intensity)→bin→推理→run/labels_per_scan/<name>.npy(uint8 0–18，19 类 remap 为 16/terrain)。
- 全量 6522 帧跑完 → semantic_label.py USE_ML=1（读 labels_per_scan+scans+poses 回投）→ 真值级 run/semantic_map.pcd → package_submission.py 重打包 submission.zip。
- run_chain.sh：等 cyl_infer 结束→校验 npy==6522→semantic_label USE_ML=1→repackage，串成一条受跟踪后台任务。
- **数据在 run/ 子目录**（run/scans、run/poses.npy、run/semantic_map.pcd、run/submission.zip），不在 slam_comp 根。
