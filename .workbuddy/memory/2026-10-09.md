### ★★ 而且"扣住"的语义是错的：它变成"可通行"

```python
np.logical_and(self.ground_ever, ~self.obstacle, out=self.ground)  # ground 是 obstacle 的纯函数
free = wmap.ground.copy()          # nav.free_space —— 规划器读的就是这个
def blocked(self): return self.obstacle | self.obstacle_now        # 安全层看的是这个（含当帧回波）
```

**被扣住的格 ⇒ `obstacle=False` ⇒ 变成 `ground` ⇒ 规划器当成"可开过去的地板"；
但 `obstacle_now` 里还有它 ⇒ `blocked()` 说"别撞"。一个语义，两个消费者，两个答案。**
⇒ 这正是 `wedge` ×4.7 / `blocked` ×3.1 的来源。上界扣住的是**任意格**（候选表尾部的），
不是机制自己判定的"门口幽灵格"，所以这 2000 多格当可通行地板 = 灾难。

诊断跑自身：traj **41.90**（ON 中位 82.4）、arrivals **0.79/1k**、wedge 235/1k、blocked 458/1k、
`ms_map` p50 91 —— **签名与 ON 臂一致**（这条本身偏坏，仅作签名校验）。

### ⑬ 第八轮：改进空间评估 + 两个新发现（boss 三问）
* **① 换 YOLO-World 有效果么？有效果但不明显。** 全量 1427 帧背靠背：
  boxes 851→706、localised 630→**611（−3%）**、实例 22→20、地图类数 5→**6**；
  **唯一真增量＝`fire extinguisher`（COCO 没有的类）25 观测/5 实例/112 点**；代价＝丢 `suitcase`/`bottle`；detect 64.6→61.7 ms。
  ⇒ 准确说法：**"花一次换模型的功夫，买到一个'以后能自己定词表'的接口，兑现率 1/3"**。**不是升级，是换了一种取舍**（backbone 更强但 320 丢小静止物）。
* **★ ② 我们一直喂 CLIP 光秃秃的名词。** 本机核实 `ultralytics/nn/tasks.py:1131 get_text_pe` **直接 tokenize 我们给的字符串，不加模板**。
  实测杠杆很大：`a photo of a fire extinguisher` **0.942** vs `fire extinguisher` **0.563**；
  描述句 `a humanoid robot standing in a room` 0.066、`a white robot with a round head` **完全无响应**（越具体越糟）。
  **但整表套模板是净回归**：51 类全套 → 框数 124→**386（+211%）**，而 **`person` 115→3**、`tv` 1→**241**。
  裁图 `out/_templ_check/full_templ51_tv_img_000018_0.93.png`：**走廊正中站着明显的人，模板模型 60 帧里 person 框是 0**，却每帧吐一个 tv。
  ⇒ **"数字大涨、地图变烂"的标本**；`min_conf=0.30` 是针对裸名词标定的，换形式后失效。**形式是杠杆，但不能整表套，必须逐类标定。**
* **★ ③ 真正的瓶颈：没有尺子。** 上面两件都指向同一件事 —— 真实侧无真值 ⇒ **所有"检出/改善"都是自证的**。
  最小可行：**人工标注 30–50 帧**，得到逐类 P/R + 物体定位误差 p50/p90，之后所有词表/模板/检测器改动都先过它。
  **没有这一步，"提升"和"打坏"长得一模一样**（§② 就是活标本）。
* **★ 外部的两个可用项**：
  - **YOLOE（清华 THU-MIG，ICCV 2025）**：三种提示模式；**视觉提示 `get_visual_pe`（给参照框，不用词）** 和
    **免提示 `set_vocab`/LRPC（内置 4585 类）** 正好绕开"文本塔看不见我们的词"。
    **★ 本机核实：`ultralytics 8.4.172` 已自带 `YOLOE`，三个 API 都在** ⇒ 接入成本≈今天换检测器（换类名+重导+同一 sidecar，仍需 `--opset 19`）。

  扣掉 `render`(58.6) 才 ~163 ms ⇒ **render 必须在关键路径外，这件事一直没做**。
