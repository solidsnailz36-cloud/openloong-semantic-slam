## 探索算法：架构 + 已判死方向

**架构**：规划 = A\*（8 连通、按半径腐蚀 + 障碍膨胀）；跟随 = 三档油门 + **视线可达前视点**；
探索 = 前沿簇 + 角扇区 + `score = size/(1+d_start)`（**离起点**）+ `sweep`（去没到过的地板）+
`island`（门口探针）+ `shadow`（死角观察位姿）。**★ 目标 = "观测位姿"**（`target_standoff_m=0.80`）。
`progress_eps_m=0.02` 必须**远小于** `sweep_stuck_improve_m=0.5`。**`n_frozen_frames` 必须永远 0。**
**★ 每个"什么都没发生"的判据都要说清盯的是哪个量**（帧数/直线/看到的地面都曾盯错）。

**仍然成立的跨轮结论**
1. **单跑不能当战果**：同构建 4 次跑的逐房间极差 ≈ 跨构建极差 ⇒ **验收一律看 N≥3 的分布**。
2. **"抽签"的机理＝1e-7 m** ⇒ 别查 random seed，修法是**排序量化**。
3. **排序层根本没有"局部"可言**：基准 `sep_min_med = 6.33 m`、`az_span_med = 157°`
   ⇒ **先量这两个数，再动排序层**。
4. **覆盖 ≈ 停留 ⇔ 被选上**（corr 0.762、反例 0）⇒ **瓶颈在"选谁"不在"能不能"**。
5. **顺路可见性是主机制**：机制是**走廊位姿的视距**，不是"路过房间"。
6. **距离的除法形式压倒价值差异**；但**在线那个 `V` 从来不结算**才是主因。
7. **不要用累积 `obstacle` 层算可视域**：首撞距离中位 0.20 m，**它不是墙图**。
8. **A/B 之前先数清两臂差几个变量**（`rfirst`+`K=4`+`sectors` 的复合里 **`K` 才是主因**）。
9. **成熟系统不拿"一坨未访问地板"当决策对象**：FUEL/ROS2 用 **frontier**、NBV 用 **RRT 采样点**、
   ASE 用 **轨迹**；**`sweep`（patch）无对应物却是实跑主力**；
   **"价值 ÷ 距离"只有我们在用**。⇒ 见 `docs/探索算法_成熟方案对标.md`。
10. **一个 case 先问它在总体里占多少**。
11. **离线 A/B 里"价值"必须按决策点时刻结算**；`ΣV` 是假指标。
12. **要"降级到 X"之前，先确认 X 不是已经失败的那一层**。
13. **救援机制"跑了" ≠ "有用"**：**验收必须含"救回到哪里去"**（救回 9 次里 7 次同一死点）。
14. **"地图不增长"不是失效判据，"原地不动"才是**（`backoff` + `|cmd_v|`=0）。
15. **"少走了 N m²"先问是"走得差"还是"被提前停掉"**：按各自起点做时间对齐曲线。
16. **★★★ 第一不可逆分叉在**地图层**，不在候选层**：`rf1r3` 的 `reach` 在 t≈66–69 s
    一次性塌掉（143.3 → 12.9 m²），同期 `blocked` 只涨 0.8 m² ⇒ **两跑建了同样的图，
    可达面积差 11 倍。**
17. **2D 栅格分不出"地面"与"它正上方的悬空结构"**：障碍证据会清零 `_ground_after`；
    `seen_mask` 只处理**天花板**（h > 2.0）。**§24 与它是同族的镜像**（一头 `votes<12` 永久封门，
    一头 2 票门槛 + `0.3×votes` 比例释放让门**先通后封**）⇒ **要修的不是阈值。**
