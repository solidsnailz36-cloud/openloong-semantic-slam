# `reach` 塌陷根因：3 格假障碍切断了 174 m²（§61）

> boss 2026-10-07 拍板：**实验名就叫 `reach collapse` 根因定位**，只做四步，**不动任何参数**
> （D1/D3/D1+D3 封板；`barren_blacklist`、sweep/frontier 参数、价值函数全部暂不动）。

**结论：命中 boss 的第二个分支 —— 地图构建把房间封死了。**
**3 个格子、每格 2 票、真值里全是自由空间，却把可达区从 175.75 m² 砍到 1.60 m²。**

## ③ `obstacle_votes`

**全部新增格的票数都是 2** —— 正好等于 `OBSTACLE_MIN_VOTES = 2`，即**刚好过线的最小值**。
⇒ 只要任何一帧少看到一次，它们就会掉回 1 票、退出障碍层。

## 完整因果链（最终版）

```
在 (−0.95, 5.95..6.15) 这 3 格 —— 真值全部自由
        ↓  每格只有 2 票（＝ OBSTACLE_MIN_VOTES 的最小值）
累积 obstacle 层把它们标成障碍
        ↓  ★ 这是那一帧唯一的变化：obstacle 3087 → 3088 格（+0.01 m²）
reach  175.75 → 1.60 m²（单帧 −174.15 m²，而 free 一格没变）
        ↓
stranded  1.15 → 148.28 m²
        ↓
sweep fresh 只剩 0.03 m²；frontier 的 6–30 个可达候选全被 barren 黑名单收走（§60）
        ↓
target = None ⇒ search（那 49 帧）
        ↓
机器人被困在 1.60 m² 里
```

**★ 3 格 × 2 票 × 0.03 m² 的假障碍，切断了 174 m²。**

### 与 §56 的强关联

那 3 格在 **(−0.95, 5.95–6.15)**，而 §56/§57 的 island 探针目标点是 **(−1.45 / −1.35, 5.95)**
—— **同一个门口，同一个 y**。而 island 探针正是在 **t=116.7 s（f499，塌陷后 8 帧）**才被触发
（因为 `stranded` 从 1.15 暴涨到 148.28 才越过 `island_trigger_m2 = 4.0`）。

⇒ **塌陷 → stranded 暴涨 → island 触发 → probe 处理完这个门口 → 没候选 → search**。
§56–§60 的整条链，起点就是这一帧、这 3 格。
