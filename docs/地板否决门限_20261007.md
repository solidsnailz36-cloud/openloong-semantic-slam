## 1. 先纠正：我上一轮给错的"地板证据"

`worldmap` 里有三个与地板有关的量，我上一轮混了：

| 量 | 语义 | 那 3 格的值 |
|---|---|---|
| `ground_ever` | **bool，一旦置位永不清零**（`|=`） | True |
| `ground`（派生层） | `ground_ever & ~obstacle`，**每帧重算** | 1220 / 1182 / 1235 帧为 True |
| **地板回波帧数**（本轮的 `gframes`） | **每帧只要有 1 个地板回波落进该格就 +1** | **27 / 19 / 33** |

**"1220 帧的地板证据"其实是"1220 帧里派生的信念说它是地板"**，而那份信念是**从 27 次观测锁存出来的**。
代码里也确实没有单调的地板计数器：`_ground_after` 会被**同一格的任何一次障碍回波清零** ——
所以一个格在被升格的那一瞬间，它的地板证据刚被擦掉，**没有资格反驳**。**这条 Bug 是真的。**
但它的尺度是 **1.4–3.7 倍**，不是 400 倍。

## 5. 实现

### 5.1 新增（都默认关 = 逐位 no-op）

`r2slam/worldmap.py`：

```python
OBSTACLE_GROUND_RATIO = 0.0        # 0 = 关（今天的出厂行为）

# 单调的地板计数：每帧只要该格有 1 个地板回波就 +1
self._ground_votes = np.zeros((n, n), np.int32)
...
# 升格处
np.greater_equal(self._obs_votes, OBSTACLE_MIN_VOTES, out=self.obstacle)
if OBSTACLE_GROUND_RATIO > 0.0:
    outvoted = (self._obs_votes < OBSTACLE_GROUND_RATIO * self._ground_votes)
    np.logical_and(self.obstacle, ~outvoted, out=self.obstacle)
```

**每帧从单调计数重算，不锁存** ⇒ 一个格若之后障碍证据反超，照样升格。**它是延迟，不是禁止。**

CLI：`replay_explore.py --obstacle-ground-ratio R`、`online_pipeline.py --obstacle-ground-ratio R`
（都设**模块属性**，因为 `WorldMap.add` 读的是模块全局；summary.json 里多一个
`"obstacle_ground_ratio"` 字段，且**从模块读**而不是从 `from ... import` 的副本读）。
