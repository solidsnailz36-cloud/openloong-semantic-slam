# 点云层判别器的离线判别实验（2026-10-07）

> **阶段定位**：K=2 已封板（暂停、不上线，见 `docs/K2多跑次验证_20261007.md`）。
> 本轮**只做一件事**：在 8 个采集上回答
> **「能不能找到一个点云层特征，把『门内假障碍/稀疏擦边』和『真实墙/家具』稳定分开」**。
> 不改探索策略 / candidate / fallback / Region-first / score；**不扫 K=3/4/5**；
> **不写判别器**（先看离线统计）。

---

## 0. 结论（先行）

**答：不能。**

在 boss 指定的三类特征（高度 / 空间邻域支持 / 点数×高度联合）里，
**不存在能把「该释放的假障碍」和「必须保留的真实结构」稳定分开的量**。三条独立证据：

1. **单变量整体分布**：判别器真正要解的那一对（**该释放 S vs 误释放 T**）的 AUC，
   全场最高 **0.675**（`每帧回波点数均值`），
   **高度只有 0.515** —— 完全抛硬币。逐 run 在 **0.457–0.769** 之间乱跳，方向都不稳定。
2. **ROC/PR 曲线上没有支配点**：把"释放精度"从 K=2 的 **71.0%** 抬到 **93.5%** 是可能的，
   但门命中率同时从 **100%** 掉到 **10.5%** —— **曲线连续、没有空档**，
   任何阈值都只是在连续曲线上取一个点，**不存在"稳定的物理区别"**。
3. **逐 run 不稳定**：看起来最干净的规则 `h_med ≥ 1.90`（精度 83%、**真值零损伤**）
   在 **6/8 个 run 上门命中率 = 0%**；它的释放精度在 0%–95% 之间乱跳。

**boss 的提醒是对的，而且现在被 8-run 真值数据证实**：
> "高度带能把桌椅排除掉" ⇒ **推翻**。
> 高度对「S vs T」的 AUC = **0.515**，两者 `h_med` 中位**都是 0.62**。

**根因（一句话）**：
> **「该释放的假障碍（S）」和「误释放的真家具（T）」在点云层是同一种东西** ——
> 都是**远处 / 掠射角 / 边缘的稀疏回波**。它们的区别**不在点云里**，而在
> 「底下有没有真值物体」，而这一点单格点云特征看不见。

**⇒ 按 boss 的事前约定：不再堆阈值，转向更成熟的地图/点云处理方式（§8）。**

## 5. ★ ROC / PR 扫描（boss 要的那张表）

**为什么要扫**：单变量 AUC 说的是整体分布。一个特征整体 overlap 大，
却可能在**尾部**很干净 —— `h_med` 就是这样（整体 S-vs-T AUC 只有 0.515，
但门内那批格子的 `h_med` 稳定在 **1.925–1.975**）。
所以必须把代价-收益曲线画出来。

**`释放精度` = 释放的格中「不在真值物体上」的比例。**
这是**不需要定义"门"**的那个量，也是判别器唯一能改善的东西。
（"门"我试过用几何定义——"释放后把 A 的两个自由分量连通"——
但它给出 86 格且定位不到 §43 那扇门，因为 `reach` 用的是**腐蚀后**的自由空间；
所以它只作参考列，不参与判定。）

|---|---|---|---|---|---|---|
| **K=2（已判死的参考点）** | **6463** | **71.0%** | 100.0% | 5.82% | **58.63%** | **1877** |
| h_med ≥ 1.70 | 465 | 74.8% | 10.5% | 0.90% | 0.00% | 117 |

### 读法（这是本轮最重要的一张表）

1. **K=2 的释放精度是最差的（71.0%）**，因为它把家具打得最狠（58.63%）。
2. **收紧阈值确实能提高精度**：71.0% → 93.5%。
3. **但门命中率同步塌**：100% → 10.5%（而且门命中在 `h` 类规则上**恒定 10.5%**，
   说明 `h` 只在门格的一小撮尾部上有效）。
4. **曲线连续、没有空档**：精度从 66.8% 到 100% 平滑变化，
   门命中从 96.5% 到 0% 平滑变化。**没有哪个点是"免费"的** ——
   这就是"不存在稳定物理区别"的定量形态。
5. **组合特征没有带来非线性收益**：`h≥1.90 & pts≤1.5`（83.7%）几乎等于
   `h≥1.90` 单独（83.4%）—— **二维联合不产生新的可分性**。
6. **`h_med ≥ 1.95` 是真值零损伤**（家具 0.00%、墙 0.05%、只有 6 格落在真值上），
   **但它只释放 93 格、门命中 10.5%** —— 它救不了门。

**§43 的"贴 `OBSTACLE_HI` 下沿的稀疏单点"这个机制在 8 个 run 上复现。**
**这不构成方案**，因为：
1. A 类**只是**假障碍的一部分（153/4586 = 3.3%）；
2. 用 `h_med ≥ 1.90` 去抓它，在 **6/8 个 run 的门上命中 0%**（§6）。

**F 类（2,625 格）是真正的杀手**：**落在真值几何上、却只有每帧 ≤2 个点**。
它们就是 K=2 的误释放，而且**与 D 类（3,708 格）在特征上完全混在一起**。

## 8. 判定与下一步

### 判定（事前写死）
> 判据：单变量 AUC ≥ 0.80 且**逐 run 方向一致** ⇒ 算"可分"；AUC < 0.65 ⇒ 分不开。

| 检查 | 结果 |
|---|---|
| 有没有单变量 AUC ≥ 0.80 分开 S vs T | **没有**（最高 0.675） |
| 有没有逐 run 方向一致 | **没有**（`h_med` 在 0.457–0.630 跨 0.5） |
| ROC/PR 曲线上有没有支配点 | **没有**（连续、无空档） |
| 二维/三维组合有没有非线性收益 | **没有**（`h & pts` ≈ `h` 单独） |

**⇒ 不能。** 按 boss 的事前约定：
**不要再堆阈值，转向更成熟的地图/点云处理方式。**

### 候选方向（**不实施，只列**；每一项都应该先做一次"离线判据 + 多 run 验证"）

1. **标准 log-odds 占据栅格 + 射线自由空间（free-space carving）** ← **首选**
   我们现在是 `ground_ever` + `_ground_after`（手写的计数与清零比例），
   它**没有"射线穿过的格"这一项**：`seen` 只标"有回波落进去的格"。
   标准占据栅格对每格累积 `log p(occupied)/(1-p)`，
   **命中 → 正证据、穿过 → 负证据**。这**不需要区分真/假**，
   它处理的是证据累积本身 —— 而 K=2 的失败正是"用一个计数阈值去替代证据累积"。
2. **局部平面性 / 法向一致性**：真结构在局部是面（法向一致），
   稀疏擦边是零散点。我们现在的 dump 里没有法向量，需要加。
3. **多帧多视角一致性**：不是"这个格被记了几帧"，而是
   "**从不同位姿看，这一格是否一致地存在**"。
   ⚠️ §42 已证门内是**横跳**的，多视角也未必救 —— 但值得测。

boss 的指示已经写死：**地图层修复一旦稳定，立即回到 GitHub 成熟探索算法源码对标。**
本轮**没有**制造任何需要继续深挖的地图 bug —— 它给出的结论是
"**这一类阈值判别器到此为止**"。所以下一步应当是：

> **①（可选、限定时间）对上面第 1 条做一次同样严格的离线判据 + 8-run 验证；

## 9. 局限（必须一起读）

1. **样本单位是格、不是回波**。同一格可能混有多帧的不同几何来源。
2. **真值几何只含碰撞体**（墙 + 家具 + 人）。所以
   `N`（保留的非真值格，10,185 格）里既有"真值物体的点云加厚"（无害），
   也可能有真值未覆盖的真实障碍 —— **`释放精度` 因此是上界**。
3. **S/T 的划分依赖 K=2 的释放集**，在 K=2 的判据维度上有偏（§1.2 已声明）；
   §3.2 的无偏对照是对这个偏差的补救，结论一致。
4. **"门"的几何定义只找到 86 格、且定位不到 §43 那扇门**（`reach` 走的是腐蚀后的
   `free_space`）。所以门命中只作参考列；**判定不依赖它**。
5. **单帧特征**。本轮没有算法向量、入射角、时间一致性（§8 的候选方向 2/3）。
6. `h` 是相对**拟合地面**的高度。
